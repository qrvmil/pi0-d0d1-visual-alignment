# π0 visual representation alignment: дизайн

Цель: выполнить весь REQUEST_RU.txt, проверить causal effect B-align против нового B-control на D2 и non-inferiority на D0. Старый B — только reference.

Из статьи https://arxiv.org/html/2510.25616 (§6, §8.2–8.5) переносим spatial cosine alignment middle backbone tokens к frozen C-RADIO teacher, предварительное обучение LN+MLP projector с frozen student, затем frozen projector. Это экспериментальная адаптация, а не буквальная реплика OpenVLA/Simpler. В π0 используем L_flow вместо cross entropy, девятый из 18 блоков PaliGemma (index 8), только visual prefix tokens и две валидные LIBERO камеры. Teacher spatial grid интерполируется bilinear до 16×16 student grid. Dummy right wrist исключается из cosine reduction. Middle state извлекается отдельным prefix-only проходом первых 9 блоков без сохранения всех hidden layers; из-за prefix attention mask он математически не зависит от action suffix. Интеграционный тест проверяет равенство выбранному состоянию full pass.

Варианты используют одну исходную pi0_base, независимую одинаковую инициализацию LoRA32, AdamW и upstream schedule. 100 demos (50 D0, 50 D1), balanced deterministic sampler, native post-action shift obs[i]→action[i+1], rotate180, resize224, K=4 deterministic image crops/brightness/contrast. Teacher и student получают одни uint8 RGB, teacher внутренний conditioner — часть encoder. Никаких OpenPI train-time augmentations. Один общий cache с ID/seed/params/checksums, fp16 spatial features, обе камеры, manifest. Нормализация только D0+D1.

Сначала driver/runtime/JAX/matmul и настоящий π0 forward/backward на synthetic batch. На текущей машине A100-SXM4-80GB: исходное заявление о RTX 6000D неверно. Blackwell compatibility нельзя объявить проверенной на A100. Минимальное обновление runtime до CUDA>=12.8 только если нужно, без притворной проверки Blackwell.

Smoke: 2 samples×4 augmentations×2 views, 1–5 updates, frozen teacher/projector, finite gradients, masks, token ordering, same init и resume. Далее projector calibration 200 updates на D0+D1, pilot 20 updates (не main run), λ стартует 0.2. В pilot r=λ||grad_align||/||grad_flow|| на общем trainable parameter set. По median последних 10 updates: r>1 → λ=0.2/r; r<0.01 → λ=min(2,0.02/r); иначе λ=0.2. Решение один раз и до main runs. r=0/nonfinite останавливает pipeline для исправления, не подбираем λ по SR. Effective batch8, уменьшение microbatch/accumulation только при измеренном OOM. Основные runs заново из исходных параметров; 3001 update, checkpoints 0/500/1000/2000/3001, финальный 3001 выбран заранее.

Evaluation: одинаковые seeds 10000–10049 и per-seed/per-step flow-noise stream. По каждой задаче paired resets hashes и noise hashes проверяются. B-original можно использовать исторические pinned 50-seed результаты с явным статусом historical reference; для причинных сравнений только новые runs. D0 расширяем до seeds10000–10499 если interim one-sided lower bound ≤−0.02; без исключения неудач. Чтобы два просмотра не увеличивали type-I error, D0 используем консервативную exact границу с Bonferroni: на каждый просмотр tail budget0.025; gain/loss multinomial marginals ограничиваем Clopper–Pearson по0.0125 каждая, lowerΔ=lower_gain−upper_loss. Она имеет как минимум95% одностороннее simultaneous coverage на два просмотра. Также отображаем обычный paired95% CI для эффекта. D2 основной outcome: pairedΔ и conservative exact95% CI (marginal Bonferroni); помогает доказано только при lowerΔ>0. Нулевое число discordant pairs не дает нулевую ширину CI. D0 lower>−0.02 → ПРОЙДЕН; верхняя граница≤−0.02 → НЕ ПРОЙДЕН; иначе НЕОПРЕДЕЛЁН. Все наблюдения сохраняются.

Публикуем только созданные weights, code/config/tests/locks/manifests/метрики/логи/небольшие видео. Dataset, teacher cache, upstream weights, credentials исключены. Все scheduled steps сохраняем. Финальный release только после evaluation и отчета с действительными числами. Цена: GPU walltime и доступная ставка; если ставка не известна, даем формулу, не выдумываем стоимость.
